Ember exposes a small public API for other plugins to interact with. The API lives in a separate Maven artifact (`sh.carr.ember:ember-api`) so you can compile against it without pulling in the full plugin.

<Note>
  Per-class JavaDocs are published separately. The pages here cover concepts and the high-level shape of the API; reach for JavaDocs when you need the precise signature of a member.
</Note>
