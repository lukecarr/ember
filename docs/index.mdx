Ember is a plugin for [Paper](https://papermc.io/software/paper/) and [Folia](https://papermc.io/software/folia/) servers running Minecraft 1.26.1 or newer.

<Note>
  Ember is in early alpha (`v0.1.0-alpha.1`). The plugin is intentionally small while the foundation lands — expect more features, and more docs, to arrive.
</Note>
