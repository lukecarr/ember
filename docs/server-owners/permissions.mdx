---
title: "Permissions"
description: "Every permission node Ember defines."
---

Ember exposes various permissions to grant access to commands and mechanics.

Grant them to your players using your permissions plugin of choice (for example, [LuckPerms](https://luckperms.net/)).

## Permission reference

| Node            | Description                                | Default | Gates                                                            | Since            |
|-----------------|--------------------------------------------|---------|------------------------------------------------------------------|------------------|
| `ember.version` | Check the running Ember version            | `op`    | [`/ember version`](/commands/version)                            | `v0.1.0-alpha.1` |
| `ember.flags`   | List and inspect Ember feature flags       | `op`    | [`/ember flags list`, `/ember flags get`](/commands/flags)       | `v0.1.0-alpha.2` |
