---
title: "Permissions"
description: "Every permission node Ember defines."
---

Ember declares its permissions in `paper-plugin.yml`. Grant them to your players using your permissions plugin of choice (for example, [LuckPerms](https://luckperms.net/)).

## Permission reference

| Node | Description | Default | Gates |
|---|---|---|---|
| `ember.version` | Check the running Ember version | `op` | [`/ember version`](/commands/version) |
