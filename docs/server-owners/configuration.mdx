---
title: "Configuration"
description: "Ember's configuration surface."
---

Ember has no `config.yml` in `v0.1.0-alpha.1`. Installing the plugin is the whole setup.

The one knob that exists today is `plugins/Ember/flags.txt`, which toggles parts of the plugin on or off at startup. See [feature flags](/server-owners/flags) for the format and the current catalog.

A `config.yml` will be introduced as configurable features land, and this page will grow with it.
