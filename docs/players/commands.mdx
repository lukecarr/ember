Each command lists the [permission](/server-owners/permissions) it requires. If you can't run one, ask your server owner to grant it.

## `/ember version`

Print the version of Ember currently running on the server.

- **Syntax:** `/ember version`
- **Permission:** `ember.version` (granted to operators by default)

**Example output**

```
Ember version: 0.1.0-alpha.1
```
