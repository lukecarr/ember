---
title: "/ember version"
description: "Print the running Ember version."
---

Print the version of Ember currently running on the server.

## Syntax

```
/ember version
```

## Permission

`ember.version` (granted to operators by default). See the [permissions reference](/server-owners/permissions) for details on granting it to players.

## Example

```
> /ember version
Ember version: 0.1.0-alpha.1
```
